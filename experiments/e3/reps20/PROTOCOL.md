# E3 重复次数 5→20：预注册（先于 20-rep 结果）

> 冻结时间：2026-11-11 21:22。回应审稿意见："n=5 时单尾 exact Wilcoxon 的最小可达 p=1/32=0.03125，
> 显著性只是样本量的产物"。

## 设计（与现有 `experiments/e3/out/` 并列，不覆盖）
- 重复：**20 次**（seed = 20261110 + r，r=0..19；前 5 次与已有 out/ 完全一致，用于一致性校验）。
- 预算：**只跑 600 s 主档**（成本考虑；300/1200 已有 5-rep 结果，不重跑）。
- 场景：full（主）、hot、edit24。
- 对比臂：全标注贪心 / 无标注代理 / 在线 bandit / FIFO / LRU / freq / random。
- 指标：评测半边（55 题）上的绝对 recall@5 与 Δrecall(pp)，逐 rep。
- 成本澄清：E3 的"修复"使用**E2 已算好的 131,028 块向量**（离线选择块，不是重新嵌入），
  因此**不需要 3.3 h 重嵌**；实测运行时间在 notes 里报（秒级到分钟级）。

## 统计（n=20）
- 配对单尾 exact Wilcoxon（n=20 最小 p≈1e-6 量级，p 有分辨率）。
- 效应量：**rank-biserial r**（主）与 **Cohen's dz = mean(diff)/sd(diff)**（辅）。
- 位置：Δrecall 的**中位数与四分位（Q1,Q3）**，不只均值。
- 主比较：**全标注贪心 vs FIFO**（FIFO 是 5-rep 下的最佳基线）；同时报 vs 无标注代理、vs online。

## 判据（写死，不改）
20 rep、full、600 s：**配对单尾 p < 0.01 且 rank-biserial r ≥ 0.5** ⇒「主结论稳健」；
否则如实降级表述（p/效应量以实际为准，不挑好看的报）。

## 附：1/32 下界说明（供论文 §5 统计与 §6.3 引用）
> n=5 的配对单尾 exact Wilcoxon 的最小可达 p 为 1/32=0.03125；5-rep 的 p=0.03125 是**可达下界**、
> 不代表效应强度。20-rep 结果（p 可低至 1e-6 量级）才作为显著性证据；5-rep 只作方向性预实验。
