# A1 在线 bandit 变体：预注册（先于正式 5-rep 结果）

> 冻结时间：2026-11-11 20:50，在正式全量跑之前。参数与判据在此写死；对 pilot（rep0）只用于
> 排除实现错误（rate 分母写错导致“摊大饼”），不作为调参依据。

## 模型（restless bandit / Whittle 指数式）
- arm = 页；奖励只在查询把它检索进 top-10 时兑现，权重 1/(rank+1)。
- 每轮：先服务 54/6=9 条历史查询（只用日志，观察 top-10），再按优先级嵌入到本轮预算耗尽。
- 优先级：`index_p = rate_p · (1 + c·sqrt(log(t+1)/(n_p+1))) · (1 + β·(round−last_repair_p)/R)`
  - `rate_p = (wsum_p + α)/(t_eff + 2α)`（每查询期望奖励；wsum 为 γ 衰减的排名加权曝光）
  - `wsum/n` 冷启动用**事故前全量索引**上的历史查询日志（同样无 gold）
  - 页内块序按内容变更幅度代理（块长/页中位）降序；页内边际收益 sqrt(n/N_p) 递减（复用 E3 贪心）
- **主参数（写死）**：R=6 轮，W=20（仅记录），α=0.1，c=0.1，β=0.5，γ=0.95。
- 敏感性网格（同时报告，不改主参数）：α∈{0.02,0.1,0.5} × c∈{0.1,0.5}。

## 评估
- 同 E3：131,028 块、109 题、场景 full/hot/edit24、预算 300/600/1200s、5 次重复（seed=20261110+r）。
- 对比臂：online / greedy-full（全标注贪心）/ greedy-nolabel（代理）/ FIFO / LRU / random。
- 指标：评测半边（55 题）绝对 recall@5 与 Δrecall(pp)；归一化恢复率仅在分母>0 且 R_after≤R_full 时给。
- 统计：5 次重复的配对差，exact 单尾 Wilcoxon。

## 判据（写死，不改）
主场景 full、600 s：
1. **优于无标注代理**：online 的 Δrecall 均值 > greedy-nolabel，且配对单尾 Wilcoxon p<0.05；
2. **接近全标注 50%**：online 的 Δrecall ≥ 0.5 × greedy-full 的 Δrecall。
两条都满足 →「在线变体有实用价值」；否则如实写「在线估计不足以替代标注信号」。
其余场景/预算只作稳健性，不参与判定。
