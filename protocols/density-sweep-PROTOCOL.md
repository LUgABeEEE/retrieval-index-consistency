# 受控块密度实验：协议（预注册，跑前冻结）

> 2026-11-11 21:55 冻结。**本文件在实验跑完前不得修改。**
> 目的：把「块密度 → PER 可观测幅度」从 3 个跨语料点（1.25 / 2.56 / 11.9）升级为**同语料受控曲线**。

---

## 1 问题

论文 §6.5 观察到：PER 的可观测幅度随「每文档块数」上升（Cmedqa 1.25 → 0.27%，T2 2.56 → 1.73%，KB 11.9 → 19.72%）。
但这三个点来自**三个不同语料**，密度与语料、语言、文档长度、qrels 粒度全部混杂。

**本实验要回答**：在同一批文档、同一嵌入器、同一 qrels 下，只改变块密度，PER 是否随之单调上升？

## 2 设计

| 项 | 设定 |
|---|---|
| 语料 | BEIR **scifact**（5,183 文档，平均 216 词，300 可评分题） |
| 密度档 k | **1, 2, 4, 6**（每文档强制切成 k 段，按词数均分） |
| 嵌入器 | bge-m3，**CLS 池化**，本机 Ollama（与主实验一致） |
| qrels | scifact 官方（文档级） |
| 评测粒度 | **双口径**：文档级（官方） + 块级（新增，块须落在 gold 文档内且 offset 对齐） |
| 事件 | 五类（add / delete / modify / rechunk）× 两档幅度（m=0.1, 1.0） |
| 四臂 | naive / prune-only / protocol / full（沿用 E2 定义） |
| 预算 | 不设（本实验只测密度效应，不测调度） |

### 为什么不上 k=8/12/16

scifact 平均文档长 216 词。k=8 → 27 词/块，k=16 → 13 词/块。
**块短于此，检索本身先失效**，测到的 PER 下降无法归因于密度。故封顶 k=6（36 词/块）。

## 3 预注册判据（跑前写死）

| 编号 | 判据 | 通过条件 |
|---|---|---|
| **H1** | PER 随密度单调上升 | Spearman ρ(k, PER@5) **≥ 0.8** 且 p < 0.05（k∈{1,2,4,6}，四点在重分块事件 m=1.0 下） |
| **H2** | protocol 臂 PER 恒为 0 | 所有 k × 两轮评测，PER@5 **恰为 0** |
| **H3** | 文档级评估稀释 PER | 每个 k：**块级 PER@5 > 文档级 PER@5**，稀释率 = 1 − 文档级/块级 > 0 |
| **H4**（辅助） | SVR 不随密度变化 | SVR 极差 < 2pp（对应 E1 的 98.5–99.2% 观察） |

**判据 H1 若失败**（非单调或 ρ<0.8）：如实报告「密度效应在本语料上不成立」，并把 §6.5 的机制解释降级为「跨语料观察，未受控验证」。**不得事后调阈值或剔除档位。**

## 5 与现有结果的关系

- 本实验**不替代** §6.5 的跨语料复现，而是补上「同语料受控」这一层
- 若 H1 通过：§6.5 的「块密度」从**假说**升级为**受控证据**
- 若 H1 失败：跨语料那条规律仍成立（三个语料都是真的），但**不能声称因果**
